## Guía de Controles
* **Movimiento:** Teclas `W`, `A`, `S`, `D` / Flechas de dirección
* **Salto:** Barra espaciadora (`Space`)
* **Interacción:** Tecla `E`
* **Correr:** Tecla Shift
* **PowerInvisivilidad:** Tecla Q
* **Atakar:** mouse derecho

---

1. **[interfas de botones]:**
